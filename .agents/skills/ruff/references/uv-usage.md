# uv Usage

uv is a Python package and project manager that replaces pip, pip-tools, pipx, pyenv, virtualenv, and Poetry.

Treat a project as uv-governed when it carries `uv.lock`, or when `requirements*` files carry the "This file was autogenerated by uv" header. Do not introduce uv into a project managed by another tool — a `poetry.lock` or `pdm.lock` names a different owner.

## Choosing A Workflow

### Scripts

For a single standalone Python file.

```bash
uv run script.py                     # Run a script
uv run --with requests script.py     # Run with an extra package
uv add --script script.py requests   # Record the dependency inline in the script
```

### Projects

For a directory with `pyproject.toml` or `uv.lock`.

```bash
uv init                              # Create a project
uv add requests                      # Add a dependency
uv remove requests                   # Remove a dependency
uv lock                              # Re-resolve the lockfile
uv sync                              # Install from the lockfile
uv run <command>                     # Run inside the project environment
uv run python -c ""                  # Run Python inside the project environment
uv run -p 3.12 <command>             # Run against a specific Python version
```

In a workspace, target one member rather than the root:

```bash
uv --directory tools/soleaux run --locked --package soleaux <command>
```

`--locked` fails instead of silently relocking, which is what makes the run reproducible.

### Tools

For a command-line tool the project does not depend on.

```bash
uvx <tool> <args>                    # Run a tool in an ephemeral environment
uvx <tool>@<version> <args>          # Pin the tool version
```

`uvx` resolves from PyPI by package name and builds an isolated environment that never reads or syncs the project environment. Run only well-known tools this way, and use `uv run` for any check that must resolve project dependencies. Reach for `uv tool install` only when the user asks for a persistent installation.

### Pip Interface

For legacy `requirements.txt` workflows with no `uv.lock`.

```bash
uv venv
uv pip install -r requirements.txt
uv pip compile requirements.in -o requirements.txt
uv pip sync requirements.txt

# Platform-independent resolution
uv pip compile --universal requirements.in -o requirements.txt
```

Use this interface only where it already exists. Do not add new `requirements.txt` files, and prefer `uv init` for anything new.

## Patterns

### Do not use pip inside a uv project

```bash
pip install requests        # Bad — bypasses the lockfile
uv add requests             # Good
```

### Do not invoke python directly

```bash
python script.py            # Bad
uv run script.py            # Good

python -c "..."             # Bad
uv run python -c "..."      # Good

python3.12 -c "..."         # Bad
uvx python@3.12 -c "..."    # Good
```

### Do not hand-manage environments

```bash
python -m venv .venv        # Bad
source .venv/bin/activate
uv run <command>            # Good
```

### Watch what `uv run` resolves

Run from a project root without `--no-project` or `--script` and uv resolves and builds that project before your command. When the command has nothing to do with the project, that is wasted work and can be very slow for a workspace with compiled dependencies.

### Keep ad-hoc reproductions outside the checkout

A scratch `.py` file inside a checkout picks up that checkout's `requires-python`, which changes the Python version tools infer. Write reproductions under `/tmp` instead.

## Migrating From Other Tools

### pyenv

```bash
pyenv install 3.12     → uv python install 3.12
pyenv versions         → uv python list --only-installed
pyenv local 3.12       → uv python pin 3.12
pyenv global 3.12      → uv python install 3.12 --default
```

### pipx

```bash
pipx run ruff          → uvx ruff
pipx install ruff      → uv tool install ruff
pipx upgrade ruff      → uv tool upgrade ruff
pipx list              → uv tool list
```

### pip and pip-tools

```bash
pip install package    → uv pip install package
pip install -r req.txt → uv pip install -r req.txt
pip freeze             → uv pip freeze
pip-compile req.in     → uv pip compile req.in
pip-sync req.txt       → uv pip sync req.txt
virtualenv .venv       → uv venv
```
