# FAQ

## Is Soleaux an AI coding agent?

No. Soleaux supplies repository intelligence to existing agents and clients.

## Is it an agent operating system?

No. The product definition is unified repository intelligence.

## Why only 12 tools?

Large root catalogs consume context and recreate MCP sprawl. Soleaux keeps the public profile fixed and loads depth through registry, resources, gateway namespaces, and explicit substitutions.

## What does `context.compile` return?

A bounded `soleaux.context/v2` packet with source evidence, owners, consumers, constraints, conflicts, validation routes, supporting facts, resources, gaps, provenance, trust, redaction, and budget measurements.

## Does Soleaux replace Claude Code, Codex, OpenCode, or Cursor?

No. It is attached to those clients.

## Does Soleaux write to their internal databases?

No.

## Is it production-ready?

No. It is `0.4.0-dev.5`; the live product-proof and later release gates remain open.

## What has been proven?

Native compilation and strict gates, the exact 12-tool profile, Context Packet V2, safe edit primitives, gateway/catalog/provisioning/governance capabilities, and independent Phase 2 artifact verification.

## What remains?

Live model proof, canonical source consolidation, real client/LSP/design-partner matrices, desktop/mobile/installers, assurance, signing, and staged release.
