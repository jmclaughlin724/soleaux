## Hero

Soleaux gives Claude, Codex, OpenCode, Cursor, and other MCP clients one native intelligence layer for repository structure, ownership, rules, skills, and validation—without flooding the model with a sprawling tool catalog.

## Feature section

### Compile context instead of dumping files

`context.compile` returns bounded source evidence, owners, consumers, constraints, conflicts, validation routes, gaps, trust, provenance, and redaction metadata.

### Keep the model-facing surface lean

The active profile has exactly 12 slots. Framework and SQL depth substitutes into a slot instead of becoming another tool.

### Use native repository intelligence

Oxc, Tree-sitter, PostgreSQL parsing, LSP semantics, Turborepo, Next.js, and a persistent index provide structural ground truth.

### Govern one catalog

Discover skills, agents, rules, ownership, tables, and namespaced MCP backends through one registry without adding root tools.

### Edit safely

Preview performs no writes. Edit applies one confirmed, unexpired, preimage-validated patch.

## Who it is for

- teams working in serious repositories;
- teams using more than one AI coding client;
- TypeScript/Turborepo/Next.js environments;
- teams that need shared governance and auditable context.
