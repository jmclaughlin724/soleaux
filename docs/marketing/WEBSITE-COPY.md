## Feature section

### Compile context instead of dumping files

`context.compile` returns bounded source evidence, owners, consumers, constraints, conflicts, validation routes, gaps, trust, provenance, redaction, and continuation metadata.

### Keep the model-facing surface lean

The active profile has exactly 12 slots. Framework and SQL depth substitutes into a slot instead of becoming another tool.

### Use native repository intelligence

Oxc, Tree-sitter, PostgreSQL parsing, LSP semantics, Turborepo, Next.js, and persistent structural state provide grounded repository evidence.

### Govern one catalog

Discover skills, agents, rules, ownership, tables, and namespaced MCP backends through one registry without adding root tools.

### Edit and recover safely

Preview performs no writes. Edit uses durable preview claims, immutable source binding, transactional rollback, atomic idempotency, and exact result replay.

### Operate one local service

The per-user daemon owns canonical state, typed local IPC, encrypted artifacts, backup, restore, repair, and service lifecycle.

### Reproducible development alpha

The unsigned alpha is built reproducibly, includes a deterministic Cargo SBOM, and has been exercised through installation, restart, doctor, backup, export, repair, restore, and uninstall.

## Who it is for

- teams working in serious repositories;
- teams using more than one AI coding client;
- TypeScript/Turborepo/Next.js environments;
- teams that need shared governance, durable local state, and auditable context.
