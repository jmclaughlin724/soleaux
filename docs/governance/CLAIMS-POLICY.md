# Claims Policy

## Current evidence level

Soleaux is a **native development product** at `0.4.0-dev.5`.

Verified claims:

- the native Rust workspace compiled and passed strict native gates through Phase 2;
- the public profile is exactly 12 slots;
- optional providers substitute rather than append;
- Context Packet V2 validates;
- gateway, catalog, adopt, attach, governance, redaction, and binary smokes passed;
- Phase 2 evidence was independently verified.

Not yet verified:

- equal-or-better live model task correctness;
- real context savings in a live same-model comparison;
- broad live client/LSP/OS compatibility;
- signed production installation;
- public production readiness.

## Approved current positioning

Use:

- “unified repository intelligence”;
- “one lean MCP”;
- “one governed catalog”;
- “bounded, provenance-tagged context”;
- “native development build”;
- “designed to reduce MCP and context sprawl”;
- “live product-proof experiment pending.”

## Claims requiring Phase 3

Do not claim these until the live comparison closes:

- reduces model context cost in real use;
- improves or preserves model task success;
- reduces tool calls in live clients;
- proven better than the baseline.

After Phase 3, use only the measured scope, model, client, repositories, and tasks.

## Claims requiring later release gates

Do not claim until Phase 7/8:

- production-ready;
- secure by external review;
- accessible;
- cross-platform parity;
- compatible with all supported clients/LSPs;
- signed/notarized/store-ready;
- generally available.

## Always prohibited or misleading

- “agent operating system” as the product definition;
- replaces Claude, Codex, OpenCode, Cursor, or the IDE;
- universal native session resume;
- bidirectional Claude Desktop hosted-memory sync;
- writes to vendor internal session databases;
- more than 12 root MCP tools;
- `1.0.0-rc.1` before release gates.

## Public evidence references

Marketing and release copy must link to:

- `PROJECT-STATUS.md`;
- the applicable phase receipt;
- independent verification;
- Phase 3 results when available;
- known limitations.
