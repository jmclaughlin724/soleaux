# Historical Documentation

Historical documents remain valuable for understanding how Soleaux reached the native unified product, but they do not own current status.

## Lineages

- **Python/FastMCP `0.1.0` lineage:** rich typed context, LSP, governance, gateway/OAuth, skills, adopt, framework discovery, editor safety.
- **Native Rust wedge:** compiled daemon/CLI, native index, bounded MCP profile, Context Packet V2, transport, crash recovery.

The native unification absorbed capabilities from both.

## Preservation

The original README, TASKS, HANDOFF, AGENTS, and CHANGELOG remain available in Git history on `main` and earlier commits. They are not duplicated here because duplicate active documents caused status drift.

See [`PYTHON-LINEAGE.md`](PYTHON-LINEAGE.md) for the capability and task mapping.
